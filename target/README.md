# Build Target Artifacts

This directory is reserved for reproducible release outputs and must not be interpreted as evidence of a production deployment.

- `deploy/` — compiled Solana SBF artifacts and keypair references generated by release tooling
- `idl/` — synchronized release IDL
- `checksums/` — SHA-256 release manifests

The placeholder address `11111111111111111111111111111111` is not a PowerChain program deployment. Private deployment keypairs must never be committed.
